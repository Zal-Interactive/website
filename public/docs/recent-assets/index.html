Recent Assets

com.zalinteractive.recent-assets

1 Quick Start

Use Recent Assets to find an asset you just worked with and open it again.

1.1 Install and open the window

  1. Install com.zalinteractive.recent-assets through Unity Package Manager. The package requires Unity 6.0 (6000.0) or newer.
  2. Open Tools > Recent Assets.
  3. Keep the window open while you perform the steps below.

The window can be empty until you change an asset in the Inspector, close a saved scene, or open a prefab. See Automatic tracking for details.

1.2 Continue with a saved scene

Read Track a saved scene for the exact steps to add a saved scene to Recent. Then use Use a row to open it or manage it.

See Use a row to choose what to do with the asset.

1.3 Choose what Recent keeps

When you want to choose how many unpinned assets to keep or which assets automatic tracking should ignore, open Settings.

2 Using Recent Assets

Recent Assets is a Unity Editor window for reopening assets you have worked with recently. It stores its lists for the current Unity project and does not add components, modify scenes, or create project assets.

2.1 Window behavior

The window has two sections:

  • Pinned: Assets you choose to keep. They stay until you unpin or remove them.
  • Recent: Assets added when supported Unity Editor events occur, such as an asset change, scene closing, or prefab opening. The newest asset appears first, and the list is limited by Max Recent Assets.

2.1.1 Use a row

When an asset appears in either section, use its row controls to choose what you want to do next.

2.1.1.1 Open an asset from its row

Figure 4

  1. Click the asset name or the row area to use Unity’s standard Open Asset action. A scene opens as a scene, a prefab opens in Prefab Mode, and other asset types open in their associated Unity editor.
  2. If the row is disabled, close the scene or Prefab Stage that is already open, then try again.

2.1.1.2 Manage an asset or clear the list

Figure 5

  1. Click Ping to highlight the asset in the Project window without opening it.
  2. Click Pin to move the asset into Pinned. Click Unpin to move it back to Recent.
  3. Click Remove to remove the entry from both sections. It does not delete the project asset.
  4. Click CLEAR to remove every unpinned asset from Recent while leaving Pinned unchanged.

2.1.2 Pin an asset from the Project window

  1. Find the asset in the Project window.
  2. Drag it into the Recent Assets window. Release it anywhere inside the window, including the empty space.

Figure 6

The asset is added to Pinned immediately. Dragging an asset into the window bypasses Banned Patterns, so use this method when you want to keep an asset that automatic tracking would exclude.

2.2 Automatic tracking

Recent Assets listens for these events only while its window is open. Leave the window open before changing an asset, closing a saved scene, or opening a prefab.

2.2.1 Track an Inspector change recorded by Undo

  1. Select a project asset under an Assets or Packages path.
  2. Change one of the asset’s settings in the Inspector. Unity records the change in Undo.
  3. Check the Recent section. The changed asset appears unless its path matches a Banned Patterns query.

2.2.2 Track a saved scene

  1. Open a saved scene from the Project window.
  2. Close the scene outside Play Mode.
  3. Check the Recent section. The scene appears when it has a project asset path.

2.2.3 Track a prefab

  1. Open a project prefab in Prefab Mode so its Prefab Stage opens.
  2. Check the Recent section. The prefab appears unless its path matches a Banned Patterns query.

Recent Assets does not watch arbitrary file changes or imports. Only paths beginning with Assets or Packages are eligible for automatic tracking. Unsaved scenes have no asset path yet, and a scene closed during Play Mode is ignored.

2.3 Settings

  1. Open Unity’s settings. On macOS, use Unity > Settings…; on Windows and Linux, use Edit > Preferences.
  2. Select Recent Assets.

Figure 7

Max Recent Assets: The maximum number of unpinned assets kept in Recent. The default is 10. Set it to 0 to discard every unpinned asset as soon as it is added; negative values are treated as 0. Pinned assets are not counted against this limit.

Banned Patterns: Queries used to exclude assets from automatic tracking. Each entry uses the same query syntax as AssetDatabase.FindAssets, for example t:Texture2D. A matching asset is skipped when it is discovered through Undo, scene closing, or Prefab Stage opening. The list is empty by default.

The recent and pinned lists are stored locally by the Editor for this project. The settings are stored in Unity’s user-level Editor preferences; they are not serialized into scenes or assets and have no effect in a Player build.

2.4 Troubleshooting

2.4.1 The window is empty

The window starts empty. Leave it open, then change an asset in the Inspector, close a saved scene, or open a prefab. If nothing appears, verify that the asset path begins with Assets or Packages and that Max Recent Assets is greater than 0 for unpinned assets.

2.4.2 A changed asset, scene, or prefab does not appear

Open Settings, expand Banned Patterns, and check whether a query matches the asset. Then confirm that you changed an asset in the Inspector, closed a saved scene, or opened a prefab.

2.4.3 CLEAR did not remove an asset

CLEAR only clears unpinned assets in Recent. Pinned assets remain; use Remove or unpin the asset first. See Use a row.

2.4.4 Clicking a row does nothing

The scene or Prefab Stage may already be open, which disables clicking the row. Close it and try again. If the asset was deleted or moved outside the project, refresh Recent Assets to remove the invalid entry.

This package runs only in the Unity Editor; it does not change your built game.

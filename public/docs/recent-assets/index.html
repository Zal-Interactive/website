Recent Assets

com.zalinteractive.recent-assets

1 Quick Start

Use Recent Assets to find an asset you just worked with and open it again. The shortest way to try it is to create a Recent item from a saved scene.

1.1 Install and open the window

  1. Install com.zalinteractive.recent-assets through Unity Package Manager. The package requires Unity 6.0 (6000.0) or newer.
  2. Open Tools > Recent Assets.
  3. Keep the window open while you trigger the workflow.

An empty window is expected before you trigger a supported event. See Automatic tracking for the events that create Recent items.

1.2 Try the basic workflow

  1. Follow Track a saved scene to create your first Recent item.
  2. Return to Recent Assets.

2 Using Recent Assets

Recent Assets is an Editor window for reopening assets you have worked with recently. It stores its lists for the current Unity project and does not add components, modify scenes, or create project assets.

2.1 Window behavior

The window has two sections:

  • Pinned: Items you choose to keep. They stay until you unpin or remove them.
  • Recent: Items added by supported Unity Editor events, with the newest item first. The list is limited by Max Recent Assets.

2.1.1 Use a row

When an asset appears in either section, first choose the row action you need.

2.1.1.1 Open an asset from its row

Figure 4

  1. Click the asset name or the row area to use Unity’s standard Open Asset action. A scene opens as a scene, a prefab opens in Prefab Mode, and other asset types use their normal Unity editor.
  2. If the open action is disabled, close the corresponding scene or Prefab Stage and try again.

2.1.1.2 Manage an item or clear the list

Figure 5

  1. Click Ping to select the asset in the Project window without opening it.
  2. Click Pin to move an item into Pinned. Click Unpin to move it back to Recent.
  3. Click Remove to delete the item from both sections.
  4. Click CLEAR to remove every unpinned item while leaving Pinned unchanged.

2.1.2 Pin an asset from the Project window

  1. Find the asset in the Project window.
  2. Drag it into the Recent Assets window. Release it anywhere in the window’s content area.

Figure 6

The asset is added to Pinned immediately. This explicit drag action bypasses Banned Patterns, so it is useful when you want to keep one otherwise-excluded asset.

2.2 Automatic tracking

Recent Assets listens for supported events only while the window is enabled. Leave the window open before you follow one of these flows.

2.2.1 Track an asset changed through Undo

  1. Select a project asset under an Assets or Packages path.
  2. Change the asset through an Inspector action that Unity records in Undo.
  3. Check the Recent section. The changed asset appears unless its path matches a Banned Patterns query.

2.2.2 Track a saved scene

  1. Open a saved scene from the Project window.
  2. Close the scene outside Play Mode.
  3. Check the Recent section. The scene appears when it has a project asset path.

2.2.3 Track a prefab

  1. Open a project prefab in Prefab Mode so its Prefab Stage opens.
  2. Check the Recent section. The prefab appears unless its path matches a Banned Patterns query.

Recent Assets does not watch arbitrary file changes or imports. Only paths beginning with Assets or Packages are eligible for automatic tracking. Unsaved scenes have no asset path yet, and a scene closed during Play Mode is ignored.

2.3 Settings

  1. Open the editor’s Preferences/Settings window.
  2. Select Recent Assets. On macOS, use Unity > Settings…; on Windows and Linux, use Edit > Preferences.

Figure 7

Max Recent Assets: The maximum number of unpinned items retained in Recent. The default is 10. Set it to 0 to discard every unpinned item as soon as it is added; negative values are treated as 0. Pinned items are not counted against this limit.

Banned Patterns: Queries used to exclude assets from automatic tracking. Each entry uses the same query syntax as AssetDatabase.FindAssets, for example t:Texture2D. A matching asset is skipped when it is discovered through Undo, scene closing, or Prefab Stage opening. The list is empty by default.

The recent and pinned lists are stored locally by the Editor for this project. The settings are stored in Unity’s user-level Editor preferences; they are not serialized into scenes or assets and have no effect in a Player build.

2.4 Troubleshooting

2.4.1 The window is empty

The window starts empty. Leave it open and follow one flow in Automatic tracking. If no item appears, verify that the asset path begins with Assets or Packages and that Max Recent Assets is greater than 0 for unpinned items.

2.4.2 A new item does not appear

Open Settings, expand Banned Patterns, and check whether a query matches the asset. Also confirm that the change used one of the supported events in Automatic tracking.

2.4.3 CLEAR did not remove an item

CLEAR only clears unpinned items in Recent. Pinned items remain; use Remove or unpin the item first. See Use a row.

2.4.4 Clicking a row does nothing

The scene or Prefab Stage may already be open, which disables the row’s open action. Close it and try again. If the asset was deleted or moved outside the project, refresh the window; invalid entries are removed during refresh.

The package is Editor-only and has no Player-build impact.
